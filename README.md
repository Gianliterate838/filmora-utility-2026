## 📋 How to Use (Step-by-Step)

### Using Export Presets

1. Open **filmora-utility-2026** by double-clicking the downloaded file.
2. Click the **"Export Presets"** tab on the left menu.
3. Choose your target platform (e.g., YouTube, TikTok).
4. Click **"Apply to Filmora"**.
5. Open Filmora and go to your export settings. The preset will already be loaded.

### Backing Up Your Project

1. Open the utility and click **"Project Helpers"**.
2. Select **"Backup Wizard"**.
3. Choose your Filmora project folder (usually in Documents > Wondershare > Filmora).
4. Pick a backup location (external drive or second folder recommended).
5. Click **"Start Backup"**. Done!

### Running Diagnostics

1. Click **"Diagnostics"** in the main menu.
2. Press the **"Run All Checks"** button.
3. Wait 10–20 seconds while tests run.
4. Review the results. Green checkmarks mean everything is good. Yellow or red warns about potential issues.

## 🧪 Troubleshooting

### The program doesn't open after double-clicking

- Make sure you extracted the file fully if you downloaded a ZIP file.
- Check that your Windows is 64-bit.
- Temporarily disable antivirus software and try again.
- Right-click the file and select **"Run as administrator"** if permission errors appear.

### Export presets don't appear in Filmora

- Close Filmora completely before applying presets.
- Run the utility as administrator.
- Check the path — make sure Filmora is installed in the default location.

### Diagnostic check shows low memory

- Close other heavy programs before running Filmora.
- Restart your computer and try again.
- Consider upgrading RAM if you work with 4K projects.
